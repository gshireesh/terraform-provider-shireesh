# Fake In-Memory Test Server

This package is generated by componentgen and provides an in-memory implementation of the gRPC service defined by the combined components proto.

Usage (in tests):

- Start server:

```go
ctx := context.Background()
svr := fakeserver.NewInMemoryServer()
httpSrv, grpcTarget, err := svr.Start(ctx)
if err != nil { t.Fatal(err) }
defer httpSrv.Close()
```

- Configure provider to point at the fake server:

```hcl
provider "shireesh" {
  api_base_url = "http://" + httpSrv.URL[7:] // use http base for gateway or set GRPC target with GRPCTarget
}
```

- Or call the gRPC client directly:

```go
conn, _ := grpc.Dial(grpcTarget, grpc.WithTransportCredentials(insecure.NewCredentials()))
cli := api.NewGrpcTerraformServiceClient(conn)
_, _ = cli.SimpleCreate(ctx, &api.SimpleCreateRequest{Item: &api.SimpleCreateInput{Score: 1}})
```
